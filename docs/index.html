2. Arquitectura de Despliegue

El proyecto ha sido desplegado utilizando una arquitectura de microservicios moderna, separando el frontend, el backend y la base de datos en diferentes proveedores en la nube para garantizar escalabilidad y mantenimiento independiente.

🖥️ Frontend

Netlify

Aplicación Vue 3 (Vite). Consume la API mediante peticiones HTTP. Despliegue continuo desde GitHub usando `netlify.toml`.

⚙️ Backend API

Railway

Servidor Node.js con Express. Maneja la lógica de negocio, autenticación, WebSockets (Socket.io) y variables de entorno seguras.

🗄️ Base de Datos

MongoDB Atlas

Clúster NoSQL en la nube. Almacena de forma segura usuarios, productos, categorías y el historial de mensajes del chat.

3. Documentación de Endpoints (API REST)

A continuación se detallan los principales endpoints disponibles en la API del backend, protegidos por políticas de CORS estrictas.

📦 Gestión de Productos

Método Ruta Descripción
GET /api/products Obtiene la lista de todos los productos disponibles.
GET /api/products/:id Obtiene los detalles específicos de un producto por su ID.
POST /api/products Crea un nuevo producto (Soporta subida de imágenes con Multer).
PUT /api/products/:id Actualiza toda la información de un producto existente.
DELETE /api/products/:id Elimina un producto del inventario de forma permanente.

📂 Categorías

Método Ruta Descripción
GET /api/categories Obtiene todas las categorías disponibles para filtrar productos en el catálogo.

🔐 Autenticación

Método Ruta Descripción
POST /login Valida las credenciales e inicia la sesión segura del usuario.
POST /register Registra un nuevo usuario en la base de datos MongoDB.
GET /logout Destruye la cookie y cierra la sesión activa del usuario.
